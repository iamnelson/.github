## 🧪 What lives here

A grab bag of proof-of-concepts and learning projects — security scanning
setups ([`poc-defectdojo-sample`](https://github.com/iamnelson/poc-defectdojo-sample)),
CI/CD wiring for Coolify deployments
([`coolify-env-demo`](https://github.com/iamnelson/coolify-env-demo),
[`home-gitops-coolify`](https://github.com/iamnelson/home-gitops-coolify)),
new-language exercises ([`ruby-calculator`](https://github.com/iamnelson/ruby-calculator),
`csharp_keepnotes`), and small product experiments like
[`pereira`](https://github.com/iamnelson/pereira), an AI-assisted platform
for condo management.

For the more polished, production-grade work — Kubernetes operators,
GitOps platforms, infra with real uptime guarantees — see
[**@nelsudev**](https://github.com/nelsudev).

## 🧭 How I use this space

- **Ship small, learn fast.** These repos are exploration first, polish
  second — a place to test a tool, a language, or an idea without the
  overhead of production standards.
- **Real tools, low stakes.** Security scanning, CI/CD, IaC — I practice
  the same tooling I use professionally, just on throwaway problems.
- **AI-assisted.** Many of these were built with heavy AI assistance to
  move fast through unfamiliar territory.
